# Agent Tickets

`agent-tickets` is the shared, local issue tracker `to-spec`, `to-tickets`, and `wayfinder` all publish to and read from. The full convention lives in [TICKET-FORMAT.md](./TICKET-FORMAT.md).

The directory itself doesn't exist yet on a fresh machine — run `agent-tickets-setup` once to bootstrap it before the first ticket is published.
