# Agent Tickets

`agent-tickets` is the shared, local git-repo issue tracker `to-spec`, `to-tickets`, `wayfinder`, `spec-pass`, `spec-loop`, and `spec-review` all publish to and read from. The full convention lives in [TICKET-FORMAT.md](./TICKET-FORMAT.md).

The repo itself doesn't exist yet on a fresh machine — run `agent-tickets-setup` once to bootstrap it before the first ticket is published.
